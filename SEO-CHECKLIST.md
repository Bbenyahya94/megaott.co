# Mega OTT Google SEO checklist

The source now includes `robots.txt` and `sitemap.xml` for `https://megaott.co`.

1. Deploy the current `dist` folder to the live domain.
2. In Google Search Console, verify `megaott.co` using the existing verification meta tag.
3. Submit `https://megaott.co/sitemap.xml` in Search Console.
4. Request indexing for the home page, Pricing, Reseller, Apps and Guides pages.
5. Keep the canonical public domain as `https://megaott.co` and redirect `www` to it, or vice versa, at the hosting level.
6. Connect the existing Google Analytics measurement ID after deployment and review Search Console Coverage reports.

SEO should be based on useful, distinct content rather than repeating a keyword unnaturally. Google does not guarantee a ranking time or ranking position.
